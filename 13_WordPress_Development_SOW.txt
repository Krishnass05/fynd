Design, develop, and optimize a secure, fast-loading WordPress website or WooCommerce store.

- M1: Environment setup and core layout build (30%)
- M2: Inner pages and plugin integration (45%)
- M3: Speed optimization, security, and migration (25%)

5. Acceptance Criteria and QA
- High performance page speed score.
- Zero plugin version conflicts or broken links.
- Easy dashboard content editing for non-technical users.
