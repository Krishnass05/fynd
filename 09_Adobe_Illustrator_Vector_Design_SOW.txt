STATEMENT OF WORK (SOW) — ADOBE ILLUSTRATOR VECTOR DESIGN
Domain: Websites, IT & Software | Active Job Volume: 204 Jobs

1. Project Objective
Create precision scalable vector illustrations, brand logos, iconography sets, and print-ready artwork.

2. Scope of Work
- Design original brand marks and vector illustrations.
- Convert raster images and sketches into clean vector paths.
- Set up artboards, color separations, and print bleeds.

3. Key Deliverables
- Editable native vector source files in AI, EPS, or SVG format.
- High-resolution transparent raster exports.
- Color palette specification sheet.

4. Milestones and Payment Schedule
- M1: Concept sketches and style alignment (35%)
- M2: Vector refinement, coloring, and typography (45%)
- M3: Final revisions and export package delivery (20%)

5. Acceptance Criteria and QA
- Pure vector paths with zero pixelation.
- Fonts converted to outlines alongside live text layers.
- Adherence to printer bleed and color specifications.
