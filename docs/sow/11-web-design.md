# Web Design and Website Design

**Category:** Websites, IT and Software
**Currency:** INR
**Rate per hour:** 1200
**Assumed total hours:** 35
**Deadline:** 10 working days

## Included deliverables
- Sitemap information architecture and wireframes for up to 6 pages (12 hours)
- High-fidelity responsive UI designs in Figma for desktop and mobile (16 hours)
- Interactive clickable prototype and design system token library (7 hours)

## Excluded (needs a change order)
- Frontend HTML and CSS code development (35 hours)
- Custom 3D renders or specialized motion design assets (18 hours)
- Copywriting content creation and stock photo sourcing (12 hours)

## Common change requests and typical extra hours
| Request a client might make | Typical extra hours |
| --- | --- |
| Design 3 additional inner website pages | 9 |
| Create dedicated dark mode UI color scheme and component variants | 8 |
| Complete interactive micro-interaction animation specs | unknown |

## Assumptions
- Client provides brand guidelines existing logo vectors and sample content.
- Figma is used as the primary design and collaboration tool.
- 2 rounds of design revisions included prior to final sign-off.
