# Data Management and Database Management

**Category:** Websites, IT and Software
**Currency:** INR
**Rate per hour:** 1300
**Assumed total hours:** 35
**Deadline:** 12 working days

## Included deliverables
- Data profiling deduplication and anomaly cleanup (14 hours)
- ETL data migration script development and test validation runs (12 hours)
- Relational schema normalization and indexing optimization (9 hours)

## Excluded (needs a change order)
- Real-time streaming data pipeline setup using Kafka or Spark (24 hours)
- Automated executive BI dashboard using Tableau or Power BI (18 hours)
- Proprietary legacy database reverse engineering (15 hours)

## Common change requests and typical extra hours
| Request a client might make | Typical extra hours |
| --- | --- |
| Build automated daily database backup and point-in-time recovery | 8 |
| Migrate legacy on-premise SQL database to AWS RDS PostgreSQL | 16 |
| Complex multi-source unstructured data parsing | unknown |

## Assumptions
- Client provides sample source datasets and secure staging database credentials.
- Maximum dataset volume covered in baseline is 500,000 records.
- 2 rounds of data validation reviews included.
